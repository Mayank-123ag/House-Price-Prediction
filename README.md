# House Price Prediction System

## Overview
This project predicts California housing prices using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Models Used
1. Linear Regression
2. Random Forest Regressor

## Results

| Model | R² Score |
|---------|---------|
| Linear Regression | 0.576 |
| Random Forest | 0.805 |

## Features
- House Age
- Median Income
- Average Rooms
- Population
- Latitude
- Longitude

## Deployment
Built using Streamlit.
